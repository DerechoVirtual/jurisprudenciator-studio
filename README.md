# Jurisprudenciator Studio

App de escritorio gratuita para abogados. Un equipo de agentes de tu propia IA (tu Claude o tu ChatGPT) redacta escritos, contestaciones y recursos en Word, y prepara informes de jurisprudencia con sentencias leídas de verdad.

**Descarga para Windows:** [Jurisprudenciator-Studio-Setup.exe](https://github.com/DerechoVirtual/jurisprudenciator-studio/releases/latest/download/Jurisprudenciator-Studio-Setup.exe)

Más información: https://jurisprudenciator.com/studio

## Qué necesitas

- Windows 10 u 11 de 64 bits.
- Claude o ChatGPT de pago en ese ordenador (la app te guía para conectarlo).
- Una cuenta de Jurisprudenciator, que es gratis.

La app se actualiza sola cuando sale una versión nueva.
